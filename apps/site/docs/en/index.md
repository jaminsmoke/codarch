![The CodArch web app with a repository open](../images/primeros-pasos-app.png)

CodArch draws the architecture map of your repository and tells you what changes in every pull request.
This documentation is for whoever installs and uses it:

- **Get started**: [installation](usar/instalacion.md) (npm, Docker or desktop) and the
  [first steps](usar/primeros-pasos.md).
- **The CLI**: one page per command; start with [`codarch analyze`](usar/cli/analyze.md).
- **The apps**: the [web app](usar/webapp.md) and the [desktop app](usar/escritorio.md), screen by screen.
- **Integrations**: the [`.codarch.yml` rules](usar/reglas.md), the [MCP](usar/mcp.md) for agents and the
  [GitHub Action](usar/github-action.md).
- **Keeping it up to date**: [updates](usar/actualizaciones.md) and the [FAQ](usar/preguntas-frecuentes.md).

:::note[Learn more]
How CodArch is built (roadmap, data model, decisions and the guide) lives in
[Development](desarrollo/index.md).
:::
