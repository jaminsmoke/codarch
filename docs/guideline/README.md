# La guía

La guía de CodArch: las ideas que todavía no son fase, con su veredicto.

- `contenido.md` — **la verdad** ✅ ✅. La web ✅ la genera ✅ ✅ (ADR 0034 ✅ ✅) ✅.

## Cómo se edita

Una idea es una sección `##` ✅ ✅ con su línea de metadatos ✅ ✅ debajo:

```markdown
## El registro público de plugins
*idea · 2026-10-21*

**Qué es** ✓: ...
```

- La línea `*veredicto · fecha*` ✅ ✅: el veredicto ✅ (`idea` ✅, `fase` ✅, `arreglo` ✅,
  `esperar` ✅ ✅) ✅ y la fecha ✅ ✅.
- Lo que **no** tenga esa línea ✅ ✅ es parte de la introducción ✅ ✅ ✅.
- Las entradas salen **en orden** ✅ ✅: la línea del tiempo ✅ ✅ de la web ✅ ✅ las sigue ✅ ✅ ✅.
- La web **agrupa** las entradas por día ✅ ✅ ✅: un nodo por fecha ✅ ✅, y las ideas de ese día ✅ ✅
  debajo ✅ ✅ ✅. Las que **esperan** ✅ ✅ van a la sección **Futuro** ✅ ✅ ✅.
- El icono de cada entrada ✅ ✅ sale de su veredicto ✅ ✅ ✅.

## Los enlaces

Los enlaces a los documentos ✅ ✅ (`../../adr/...` ✅ ✅) salen hacia el repo ✅ ✅ ✅, que es donde
están ✅ ✅ ✅.
